# Smart Movie Picker для Lampa

Плагин для [Lampa](https://github.com/lampa-app/LAMPA), который решает вечную проблему «что посмотреть сегодня». Вместо бесконечной ленты каталога — короткая подборка из 5–10 фильмов под настроение, с учётом того, что вы уже смотрели и оценивали.

## Установка

**Настройки → Расширения → Добавить плагин** → вставить ссылку:

```
https://belikov072014-alt.github.io/plugin-lampa/smart_movie_picker.js
```

Перезапустить Lampa.

## Что умеет

В главном меню появляется пункт **🍿 Что посмотреть?** со списком режимов:

- **❤️ Наш вечер** — подборка на основе персональных предпочтений (см. ниже)
- 🔥 Захватывающее, 🤯 С неожиданной концовкой, 😂 Лёгкое и смешное, 😈 Триллер/детектив, ⏱ До 2 часов, ⭐ Высокий рейтинг, 🆕 Поновее, 🎲 Удиви меня — жанрово-рейтинговые фильтры TMDB
- 🎬 / 🏝 / ⚖️ «Похоже на …» — подборки на основе `TMDB /recommendations` для конкретных фильмов-ориентиров

На карточке любого фильма — кнопка **🍿 Оценить**:

- 👍 Нравится
- 👎 Не нравится
- 👁 Уже смотрели
- ⏭ Не сейчас (скрыть временно)

Плагин запоминает эти оценки локально на устройстве (`Lampa.Storage`) и:

- не показывает повторно то, что вы уже отметили или видели последние 30 дней;
- считает вес жанров — 👍 повышает вес жанров фильма, 👎 понижает, и это влияет на ранжирование во всех режимах, не только в «Наш вечер».

## Технические детали

- Работает через встроенные `Lampa.Api` / `Lampa.Storage` / `Lampa.Select` / `Lampa.Menu` — свой сервер и свой TMDB API-ключ не нужны.
- Все данные (оценки, история показов, веса жанров) хранятся только на этом устройстве, синхронизации между устройствами нет.
- Список зарегистрированных TMDB-жанров и параметры discover-фильтров соответствуют официальному API TMDB.
